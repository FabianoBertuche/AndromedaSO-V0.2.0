# PRD MVP04: Provider Management

## Objective

Deliver a production-ready provider management surface with real-time sync, benchmark, and routing visibility in Model Center.

## Success Criteria

- localhost:5173/models exposes Add, Sync, and Benchmark interactions live.

## Acceptance Criteria

- CRUD-like provider lifecycle with real-time health visibility.
- Ollama/OpenAI sync flow reaches 100% completion for known provider templates.
- Router auto-selection for coding prefers GPT-4o.
- Benchmark suite supports 20 tasks and displays score table.

## UX Direction

- Neon matrix visual language
- Fast feedback on sync, health, and benchmark execution
- Clear ranking and routing decision history for operators
